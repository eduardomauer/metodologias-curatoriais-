# Rights and Access Matrix

This file defines what belongs in this public repository and what must remain outside it.

## Publication levels

| Level | Description | Rule |
|---|---|---|
| Public | Reviewed documentation intended for citation and public reading | Allowed here |
| Protected | Method, visual language, asset, draft or research element not intended for open reuse | Keep outside this repository |
| Internal | Operational or institutional material requiring controlled access | Keep outside this repository |
| Pending review | Material awaiting provenance, authorship, licence or validation check | Do not publish yet |

## Default rules

Public material may be included only when it is reviewed, versioned, sourced and licensed.

Protected material must not be converted into public documentation by accident. Public summaries may describe the existence of a method, archive or asset, but they must not expose source files, reusable protected elements or internal procedures.

## Authorship separation

Keep the following layers distinct:

- Associação MILK: institutional entity.
- Atlas Vivo MILK: cultural atlas and governed methodological ecosystem.
- Eduardo Mauer: authorial, curatorial and methodological work.
- Nuno A.: photography, digital artwork and authorised visual contributions when applicable.

## Licence caution

The repository licence applies only to materials explicitly prepared for public release. It does not automatically open protected assets, internal files, pending-review materials or third-party works.
