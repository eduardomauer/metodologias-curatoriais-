# Metodologias Curatoriais

**Sistema Integral de Criação de Dispositivos Territoriais**

Este repositório reúne fundamentos, aplicações e materiais de trabalho relacionados ao desenvolvimento de metodologias curatoriais voltadas para território, memória, arte, cultura e mediação crítica.

## Estrutura

O repositório está organizado em duas partes principais:

### FUNDAMENTOS
Reúne bases conceituais, referenciais teóricos, princípios metodológicos e textos estruturantes do projeto.

### APLICAÇÕES
Reúne desdobramentos práticos, exercícios, dispositivos curatoriais, estudos de caso, protótipos e materiais aplicados.

## Objetivo

Este espaço funciona como um ambiente de organização, documentação e desenvolvimento de uma metodologia curatorial integrada, permitindo articular pensamento crítico, experimentação prática e construção territorial.

## Uso

O repositório pode ser utilizado para:

- organizar documentação curatorial;
- reunir textos-base e referências;
- desenvolver aplicações práticas;
- estruturar processos de pesquisa, criação e mediação;
- acompanhar a evolução do projeto ao longo do tempo.

## Estrutura de pastas

```text
FUNDAMENTOS/
APLICACOES/
README.md
```
