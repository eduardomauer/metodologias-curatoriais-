# Metodologias Curatoriais

**Sistema Integral de Criação de Dispositivos Territoriais**  
**Autor:** Eduardo Mauer · Associação MILK · Lisboa, Portugal

Este repositório reúne fundamentos, aplicações e materiais de trabalho relacionados ao desenvolvimento de metodologias curatoriais voltadas para território, memória, arte, cultura e mediação crítica.

---

## O que é este repositório

Este espaço funciona como um ambiente de organização, documentação e desenvolvimento de uma metodologia curatorial integrada.  
Aqui se articulam pensamento crítico, experimentação prática e construção territorial a partir de dispositivos como oficinas, mapas participativos, arquivos abertos, intervenções urbanas e sistemas de dados.

---

## Estrutura de pastas

```text
FUNDAMENTOS/
APLICACOES/
README.md
```

- **FUNDAMENTOS/** – bases conceituais, referenciais teóricos, princípios metodológicos e textos estruturantes do projeto.  
- **APLICACOES/** – desdobramentos práticos, exercícios, dispositivos curatoriais, estudos de caso, protótipos e materiais aplicados.

---

## Como este repositório pode ser usado

Este repositório pode ser utilizado para:

- organizar documentação curatorial;
- reunir textos-base e referências;
- desenvolver aplicações práticas em território;
- estruturar processos de pesquisa, criação e mediação;
- acompanhar a evolução do método ao longo do tempo.

---

## Outros desdobramentos

Parte desta metodologia se articula com o projeto **Atlas Vivo MILK** (cartografia de memória intangível portuguesa) e com o **Método Curatorial de Dramaturgia Urbana e Memória**, documentado em repositório próprio.
