# Metodologias Curatoriais
## Sistema Integral de Criação de Dispositivos Territoriais

> *O território é uma sala de aula que ainda não sabe que é um palco. O meu método é o acontecimento que os faz descobrir isso ao mesmo tempo.*

**Autor:** Eduardo Mauer · Associação MILK · Lisboa, Portugal

---

## O que é este repositório

Um **motor gerativo** de dispositivos territoriais — oficinas, mapas participativos, arquivos abertos, intervenções urbanas, sistemas de dados, protocolos de memória.

Nasce do cruzamento de três corpos de conhecimento:

| Origem | Conceito central |
|--------|-----------------|
| Dissertação de Mestrado (2009) | Dialogia lúdica — Bakhtin |
| Teatro de rua / Invasão urbana | Território como dramaturgia — Carreira |
| Desenvolvimento simbólico | Jogo como forma de conhecer — Piaget |

---

## Os 7 Fundamentos

| Código | Princípio |
|--------|-----------|
| F1 | **Dialogia** — toda enunciação é relacional |
| F2 | **Agir comunicativo** — ação legítima nasce do entendimento mútuo |
| F3 | **Ludicidade** — o brincar é modo de conhecer |
| F4 | **Alteridade** — o outro é condição, não obstáculo |
| F5 | **Arte aberta** — o dispositivo tem lacunas para o participante preencher |
| F6 | **Dignidade** — nenhum dispositivo que silencie é aceitável |
| F7 | **Linguagem como ação social** — cada palavra institui relações de poder |

---

## Os 10 Eixos Geradores

| Eixo | Pergunta orientadora |
|------|---------------------|
| E1 — Enunciação | Quem fala, para quem, com que corpo? |
| E2 — Ludicidade | Qual é a brincadeira séria que estrutura esta experiência? |
| E3 — Territorialidade | A que espaço e comunidade este dispositivo responde? |
| E4 — Temporalidade | Em que ritmo acontece? Tem memória? Tem devir? |
| E5 — Coalizão | Que atores se unem, em que configuração? |
| E6 — Conflito produtivo | Que tensão este dispositivo activa intencionalmente? |
| E7 — Memória e herança | Que legados preserva ou reinterpreta? |
| E8 — Corpo e presença | Qual o papel do corpo, do gesto, da voz? |
| E9 — Tecnologia | Que instrumentos digitais potenciam sem substituir a dialogia? |
| E10 — Avaliação viva | Como se sabe que o dispositivo funcionou? |

---

## As 4 Operações

| Operação | Descrição |
|----------|-----------|
| **Amplificação** | Uma voz existente ressoa mais amplamente |
| **Fricção Produtiva** | Dois elementos que não se encontram são postos em diálogo |
| **Lacunação Intencional** | Dispositivo incompleto — convida o participante como co-autor |
| **Retorno e Devolutiva** | O que foi produzido volta ao território com forma utilizável |
