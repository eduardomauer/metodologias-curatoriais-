# Governance Policy

This repository is a public documentation layer for reviewed MILK curatorial methodologies. It is not the operational repository of the Atlas Vivo MILK, the OCSR, private research files, protected visual assets, internal inference methods or confidential strategy.

## Responsible entity

Association: **Associação MILK — Movimento de Intervenções e Linguagens Kulturais e Arte**  
Public authorial layer: **Eduardo Mauer**  
Repository scope: public, reviewed curatorial documentation.

## Governance principles

1. **Human validation is mandatory.** No structural, legal, ethical, curatorial or authorship decision is delegated to automated systems.
2. **No regression.** Additions must preserve validated content, provenance, authorship, access level and versioning.
3. **Layer separation.** Public documentation must remain separate from protected methodology, restricted assets, confidential records and personal data.
4. **Provenance before publication.** Every public file must identify title, responsible entity, date, version, licence, access level and validation status.
5. **Rights before reuse.** No asset, image, testimony, photograph, unpublished document or curatorial mechanism may be published unless rights, consent and access level are clear.
6. **Institutional clarity.** Associação MILK, Atlas Vivo MILK, Eduardo Mauer and Nuno A. must not be merged into a single authorship layer unless a file explicitly states the relevant role.

## Public release rule

A file is public-ready only if it satisfies all of the following conditions:

- it contains no credentials, tokens, secrets or private configuration;
- it contains no personal data unless lawfully public and intentionally included;
- it contains no restricted Atlas/OCSR method, internal engine or confidential strategy;
- it contains no unlicensed or unvalidated asset;
- it states provenance, responsible entity, licence, version, access level and validation status;
- it can be cited without exposing private or protected material.

## Access levels

| Level | Meaning | Publication status |
|---|---|---|
| Public | Reviewed material prepared for citation and public reuse under stated terms | May be published |
| Protected | Methodological, curatorial, visual or intellectual-property material not intended for open publication | Do not publish here |
| Confidential | Personal data, private correspondence, internal strategy, operational credentials, contracts or unpublished restricted records | Forbidden in this repository |
| Pending review | Material awaiting rights, authorship, licence or provenance confirmation | Do not publish until reviewed |

## Change control

All changes should be made through a separate branch. Direct edits to the default branch should be avoided unless the change is minor, reversible and already validated.

Every substantive change should state:

- what changed;
- why it changed;
- which files were affected;
- what remained intact;
- regression risk;
- validation or review method.

## Protected exclusions

The following must not be committed to this repository:

- private Drive exports;
- unpublished contracts;
- personal data;
- community records not cleared for publication;
- Atlas Vivo MILK internal engines;
- OCSR private analytical layers;
- restricted curatorial mechanisms;
- high-resolution visual assets;
- unlicensed photographs;
- credentials, tokens, OAuth secrets or API keys;
- files containing unreviewed AI traces, unverified claims or unverifiable authorship.

## Review authority

Final validation remains human, institutional and contextual. Automated tools may assist with formatting, metadata, syntax, consistency checks and documentation drafts, but they do not decide publication, authorship, licence, ethical status or legal sufficiency.
