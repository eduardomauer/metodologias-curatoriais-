# Checklist de Publicação

Antes de integrar qualquer conteúdo no Atlas ou tornar público, verificar:

## Conteúdo
- [ ] O texto está em linguagem clara (ISO 24495-1)
- [ ] Não contém dados pessoais ou informação confidencial
- [ ] A proveniência está declarada
- [ ] A versão está identificada

## Conformidade
- [ ] Conformidade WCAG 2.2 verificada (se aplicável)
- [ ] Licença EUPL-1.2 declarada
- [ ] GDPR verificado (sem dados pessoais expostos)

## Governança
- [ ] Gate de validação executado
- [ ] Frase-gatilho fornecida: *"validação e assinatura diário"*
- [ ] Registo de responsabilidade preenchido e assinado
- [ ] Hash SHA-256 gerado

## Integração Atlas
- [ ] Estado alterado para `aprovado-humano`
- [ ] Integrado no Atlas com estado `integrado-atlas`
- [ ] Changelog atualizado
