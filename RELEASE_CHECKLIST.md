# Release Readiness Checklist

Use this checklist before any public release, archival deposit or external institutional sharing.

## Repository status

- [ ] Work is on a dedicated branch.
- [ ] The default branch was not modified without review.
- [ ] The diff is readable and limited to the stated task.
- [ ] No unrelated files were changed.
- [ ] No validated content was weakened or deleted.

## Public-readiness check

- [ ] No operational credentials or private configuration are present.
- [ ] No personal data is present unless lawfully public and intentionally included.
- [ ] No private correspondence or unpublished restricted record is present.
- [ ] No internal OCSR analytical layer is present.
- [ ] No protected Atlas Vivo MILK method or curatorial engine is present.
- [ ] No restricted visual asset, unlicensed photograph or pending-rights material is present.
- [ ] No unvalidated testimony or community record is present.

## Metadata check

- [ ] README is current.
- [ ] CITATION.cff is current.
- [ ] codemeta.json is current, when applicable.
- [ ] CHANGELOG.md is current.
- [ ] Licence and access level are clear.
- [ ] Authorship and institutional responsibility are clear.
- [ ] Version and date are clear.
- [ ] Provenance is stated.

## Rights and reuse check

- [ ] Licence does not accidentally open restricted material.
- [ ] Public documentation and protected methodology are separated.
- [ ] Associação MILK, Atlas Vivo MILK, Eduardo Mauer and Nuno A. remain correctly distinguished.
- [ ] Reuse conditions are explicit.
- [ ] Materials pending rights review are excluded.

## Interoperability check

- [ ] Repository can be cited.
- [ ] Metadata supports archival deposit.
- [ ] Public documentation can be understood without private files.
- [ ] External users can identify scope, limits, licence and responsible entity.

## Final human validation

- [ ] Human maintainer reviewed the diff.
- [ ] Human maintainer confirmed public-readiness.
- [ ] Release notes state what changed and what remained protected.
